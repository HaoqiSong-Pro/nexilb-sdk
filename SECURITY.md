# Security policy

The current supported release line is NexiLB v1.0.0.

Report suspected vulnerabilities, leaked private implementation details,
credential exposure, malicious packages, or release-integrity failures
privately to `haoqisong@126.com`. Include the affected file or release asset,
its SHA-256 digest, the observed behavior, and a minimal reproduction that
contains no applicant data or secrets. Do not publish exploit details or send
private keys, passwords, personal identity documents, or confidential source.

A report does not authorize testing outside systems and data controlled by the
reporter. Affected release assets will be withdrawn or replaced after triage.
