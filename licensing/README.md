# Licensing entry

The approved project license is `LicenseRef-NexiLB-Research-Use-1.0`; its exact
text is the root `LICENSE.md`, bound by SHA-256 in `license-metadata.json`.
Repository access and downloads still grant no use rights: every permitted use
requires the separate written authorization described by that license.

`application-link.template.json` is a machine-readable description of the
offline email channel; it is not an online endpoint and does not issue an
authorization. Applicants must use `OFFLINE-APPLICATION.md` and read the
versioned `PRIVACY-NOTICE.md`. `WRITTEN-AUTHORIZATION-TEMPLATE.md` shows the
minimum content of the separate written instrument but is itself not an
authorization. This custom research-use license is not an open-source license.
