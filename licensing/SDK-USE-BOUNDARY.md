# SDK download and use boundary

Repository visibility and download access do not grant a right to use,
execute, deploy, embed, modify or redistribute the SDK or a runtime. Use
requires a separately approved `LicenseRef-NexiLB-Research-Use-1.0` authorization
for the named applicant, project, version and scope. This custom research-use
license grants only the permissions stated in that separate authorization.

The approved license text is `LICENSE.md`. The only application channel
described by this SDK is the offline email procedure in
`OFFLINE-APPLICATION.md`; there is no online application endpoint and no
automatic issuance. The application descriptor binds the exact privacy notice,
application form and authorization template by SHA-256. An application or
receipt acknowledgement grants no rights; only a separately issued written
authorization does so.
